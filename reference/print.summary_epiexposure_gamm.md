# Print an EpiExposure GAMM summary

Print an EpiExposure GAMM summary

## Usage

``` r
# S3 method for class 'summary_epiexposure_gamm'
print(x, ...)
```

## Arguments

- x:

  An object returned by \`summary.epiexposure_gamm(component =
  "both")\`.

- ...:

  Additional arguments passed to the component print methods.

## Value

The summary object, invisibly.
