# Example dataset for EpiExposure package

Daily weather and disease observations used to demonstrate DLNM
workflows.

## Usage

``` r
TargetSpot
```

## Format

A data.frame with N rows and the following variables:

- epi_id:

  Experimental unit identifier

- dpp:

  Days post planting

- tmean:

  Mean temperature (°C)

- vpd:

  Vapor pressure deficit

- rain:

  Daily rainfall

- y:

  Disease response (e.g., binary or severity)

## Source

Field experiment or simulated data
